Mac 怎么批量给视频
加水印和片尾？

把一套水印、Logo 和落版配置保存为方案，为同一个文件夹的视频重复使用。视频读取与导出在本地完成，无需上传素材。

本教程适用于当前公开的 macOS Apple Silicon 安装包。先用复制的少量视频跑通流程，再处理正式素材。

1 · 准备素材

准备一个输入视频文件夹、水印或透明底 Logo，以及一段片尾视频。使用独立输出目录，测试时先复制两三条素材。

静态水印使用 PNG 图片；动态水印使用兼容的动态素材。首次使用可以先只配置 PNG 水印和拼接落版。

2 · 添加输入和水印

打开桌面工具的「视频批处理」页，选择或拖入输入文件夹。在左侧勾选「静态水印」，选择图片，在中间设置位置与大小。

需要背景海报和独立 Logo 布局时，使用「可视化叠加」。动态水印涉及透明度时检查颜色保护，避免颜色发灰或发黑。

3 · 正片结束后接落版

勾选「拼接落版」，选择片尾视频。需要片尾自己的声音时，启用保留落版原声。

「浮层落版」是叠在正片最后几秒的另一种效果。本教程使用拼接方式，两者不要混淆。

4 · 检查处理顺序

查看已启用功能与执行顺序。如果只想让水印出现在正片上，先处理水印，再拼接片尾；顺序变化可能让片尾也参与后续包装。

若还要统一改尺寸或贴背景，检查最终尺寸和落版的比例是否一致。先做预览确认实际结果。

5 · 预览，再保存模板

检查开头约 3 秒的水印位置，再检查结尾片段的衔接和片尾声音；有疑问时播放完整测试成品。

确认后保存为「飞跃-水印与片尾」方案。软件会随方案记住水印、Logo 和落版文件的路径。下次加载方案即可复用，不用反复选择这些素材；文件被移动或删除后需重新选择路径。

6 · 批量导出与核对

选择输出文件夹，开始处理，通过进度和日志查看结果。检查成品数量、时长、画面、水印、片尾原声和文件名。

同一批素材需要不同尺寸或不同片尾时，保存多套完整方案，再进入「批量裂变」，按方案名建立输出子文件夹。

效果怎么检查？

预期结果是：正片显示所选水印，结束后接片尾；启用保留原声时，片尾自己的音频正常播放。下面可观看产品介绍，也可以进入示例工作台体验布局。

产品介绍展示整体功能，不是本教程每一步的连续录屏。真实批量导出需使用桌面工具。

常见问题

水印挡住字幕怎么办？

调整位置与大小；画面不同的素材先逐条检查，必要时单独微调。

片尾没有声音怎么办？

确认片尾源视频有音轨，并检查保留原声设置与播放音量。通过结尾预览和完整成品核对。

拖入文件夹没反应怎么办？

使用选择文件夹按钮，先试少量本地素材。仍失败时保留日志，通过 GitHub Issues 反馈。

能保证 100 条视频几秒导出吗？

不能。配置操作与编码耗时不同；导出时间取决于视频数量、时长、分辨率、功能和电脑性能。
