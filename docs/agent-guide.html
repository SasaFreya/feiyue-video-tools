给 Agent 读取的纯文本说明 ↗

01 · 选择安装包

先告诉助手你的系统和芯片。当前推荐包适用于 macOS Apple Silicon（M 系列）。

打开下载页

下载并完整解压，首次右键打开 App。当前安装包未经过 Apple 公证，按系统提示处理拦截。

02 · 说清处理目标

告诉助手你的输入目录、输出目录，以及需要的尺寸、背景、Logo、水印、落版和命名规则。

浮层落版叠在正片末段；拼接落版接在正片结束后。需要落版声音时，检查保留原声设置。

03 · 先跑少量素材

复制几条素材到测试文件夹，使用独立输出目录。配置功能与执行顺序，先预览，再保存为模板。

有电脑操作能力的 Agent 可以在你的授权范围内协助；只有聊天能力的助手会逐步指导你。

04 · 检查，再批量执行

  • 尺寸、背景与 Logo 位置是否正确
  • 水印、正片与落版衔接是否正常
  • 落版原声、时长与文件名是否符合预期
  • 成品是否进入正确的方案文件夹

确认测试结果后，再处理整批素材。命名或覆盖文件前先核对操作范围。

遇到问题怎么办？

拖入无效可尝试文件夹选择按钮。启动或导出失败时，记录系统、芯片、操作步骤和日志，通过 GitHub Issues 反馈。

网页演示不能执行完整视频编码。工具当前没有专用 Agent API；助手应如实说明它能操作和已检查的内容。
