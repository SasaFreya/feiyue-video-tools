视频创作中，很多时间花在相同的步骤上：给不同素材添加同一个 Logo，统一背景，拼接片尾，再整理文件名。

飞跃把这些操作集中到桌面工作台，用方案模板保留配置，用批量裂变组织多套输出。这个项目探索的是：如何把日常工作的具体需求，变成真正能用的工具。

使用教程

先学一个功能，再把它们组合成可复用方案。

准备好素材，包装过程交给飞跃。

准备你的 Logo、落版、水印，或者一份字幕、背景图，把需要的功能与顺序组合成方案，再交给飞跃批量处理。

发挥想象力，不必被功能名字限制：先想清楚你要的画面，再选择能实现它的功能。组合工作流可以自由搭配，下方只是几个例子；实际效果先通过少量素材预览确认。

选好方案、启动处理后，你可以继续做其他事情。处理完成后，飞跃会提醒你；打开输出文件夹，检查成品画面、声音和数量，完成验收。

你可能想了解

动态水印如何添加？

桌面版本导入带透明通道的 MOV 文件，可全屏贴合或自定义位置。网页里的文字拖动仅用于布局预览。

这个工具包含 AI 生成功能吗？

目前专注本地视频包装与批量工作流；宣传片的合成配音属于视频制作，不是工具内功能。

网页演示和桌面工具有什么区别？

网页沿用桌面版顶部页面切换和左中右工作台分区，提供部分功能预览：背景合成、Logo 水印、正片结束后接落版并保留落版原声，以及命名与裂变流程。完整的视频读取、编码和批量导出由本地桌面工具执行。

批量裂变是什么意思？

同一组素材按多套完整方案分别处理。每个分支可以引用不同模板，并输出到独立文件夹，便于后续整理。

视频素材需要上传吗？

本页使用提供的视频、插画背景和示例文件名，无需上传素材。桌面工具读取本地文件，并将成品写入你选择的输出目录。

在哪里获取工具？

你可以查看 GitHub 项目与现有下载包。飞跃视频批处理工具 安装包已提供下载，适用于 macOS Apple Silicon。
