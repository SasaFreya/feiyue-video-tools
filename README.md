**飞跃是一款在自己电脑上运行的视频批量处理工具**，围绕视频包装、规范命名与多方案输出，把重复步骤保存为可复用的方案。

例如，你剪好了一个文件夹的视频，需要统一加 Logo、水印和落版，再输出几套不同比例的包装。你可以先配置方案，以后直接套用；同一组素材也可以按多套方案分别处理，自动建立输出子文件夹。

视频读取与导出在本地完成，无需把素材上传到网站。本仓库提供产品介绍、官网页面和安装包下载，**桌面工具源代码不公开**。

## 1. 适合谁

- **信息流与买量视频剪辑师**：重复添加品牌包装，交付多套方案。
- **内容创作者**：统一 Logo、声明水印和片尾，减少逐条操作。
- **团队素材管理人员**：按字段与标签规范命名，整理不同方案的输出。

## 3. 核心功能

### 3.1 视频批处理：一套包装，多次复用

| 功能 | 可以做什么 |
|---|---|
| 视频裁切 | 保留或删除指定时间段，处理末尾的 N 秒 |
| 批量改尺寸与比例适配 | 对同批视频统一调整输出尺寸或比例，以模糊背景承接原视频画面 |
| 动态水印 | 导入动态水印素材，配置位置与相关参数 |
| 静态水印与 Logo | 添加品牌 Logo 或声明图片，调整位置与大小 |
| 浮层落版 | 在结尾前叠加落版素材，与原视频画面重叠展示 |
| 拼接落版 | 正片结束后接落版，可保留落版原声 |
| 批量换背景图 | 在可视化叠加中使用自备背景图或背景视频，制作 9:16、16:9、1:1、4:5 等包装布局 |
| 批量贴 Logo | 在可视化叠加中统一 Logo 位置，也可针对每条视频单独微调 |
| 方案模板 | 保存功能配置与素材路径，后续重复使用 |
| 局部预览 | 先检查开头、中间或结尾的处理效果，再批量导出 |

功能可以按需勾选，执行顺序可以调整。字幕相关功能仍在完善中，使用范围和限制见下方说明。

### 3.2 预览与素材复用

选中输入视频后，可在中间画布查看预览帧，辅助判断画面与包装的位置；支持放大查看。智能预览或手动选择短片段，可以检查开头、中间或最后约 3 秒的处理效果。

资产库可以导入常用素材或引用素材路径；方案模板保存配置，方便下一次复用。动态水印涉及背景色与透明度时，可检查颜色保护设置，避免水印发灰或发黑。

### 3.3 字幕：识别大意与批量烧录

- 识别阿拉伯语、土耳其语等视频语音，导出 SRT，辅助理解视频大意。
- 使用一份已有 SRT，为同批视频烧录相同字幕。
- 多份 SRT 匹配对应视频后烧录字幕。

作者在无背景音乐的阿语、土语素材上体验到约 80% 的识别准确率；这是特定素材的使用反馈，并非标准评测或效果保证。口音、音乐和录音质量都会影响结果，需要人工核对。识别功能需要额外的 Whisper 环境，安装包不内置模型。

字幕暂不作为裂变分支直接支持的步骤；需要时在单方案批处理或预处理阶段配置。

### 3.4 规范命名：把交付规则变成模板

- 自定义命名字段及字段顺序，组合序号、品牌、日期、作者和标签。
- 日期可随电脑日期更新，常用标签可维护和复用。
- 对照查看原文件名与新文件名，确认后执行；个别条目可微调。
- 支持对照更名及附加命名等方式，适配不同整理习惯。

命名会修改文件名，第一次使用建议先拿复制的素材文件夹试跑，并检查预览结果。

### 3.5 批量裂变：一组素材，输出多套完整方案

每个分支是一套完整方案，而不是单独一个功能。可以引用已有模板，也可以保存自己的组合。

```text
一组输入视频
    ├── 方案 A：水印 → 落版 → 1:1 背景包装
    ├── 方案 B：水印 → 落版 → 16:9 背景包装
    └── 方案 C：自定义功能与执行顺序

输出根目录/
    ├── 方案 A/
    ├── 方案 B/
    └── 方案 C/
```

上面是工作流示例，实际尺寸、素材和执行顺序由你配置。支持组织多个输入单元，并按方案自动建立输出文件夹；需要先统一处理素材时，可配置预处理方案。

### 3.6 多方案处理流程

```mermaid
flowchart TD
    A[选择一组或多组输入视频] --> B{是否启用预处理}
    B -->|是| C[先执行预处理方案]
    B -->|否| D[读取当前输入单元的方案列表]
    C --> D
    D --> E[加载下一套完整方案]
    E --> F[按自定义顺序执行功能]
    F --> G[写入输出根目录下的方案文件夹]
    G --> H{还有方案或输入单元吗}
    H -->|有| D
    H -->|没有| I[查看成品与处理日志]
    I --> J[按需规范命名并交付]
```

### 3.7 队列、监视与使用偏好

生产队列用于把多次批处理或裂变任务排好顺序。监视文件夹可以扫描子文件夹并加入队列，实际处理仍需启动队列；不是开启监视后就自动完成所有导出。

设置中可以记住默认启动页面、自动加载方案等使用偏好，并选择奶油粉白、蓝白、黄绿、黑紫等主题。队列与监视属于进阶功能，第一次使用建议从普通单方案批处理开始。

## 4. 工作台操作详解

### 4.1 输入、模板与常用素材

1. **添加输入**：选择文件夹或拖入文件夹，检查列表中的素材与数量。拖入不可用时可改用选择按钮。
2. **加载方案**：在方案模板列表中选中模板并加载，检查勾选功能、参数以及素材路径。
3. **保存复用**：配置好一套包装后保存为模板，下次继续使用；修改模板前先确认正在编辑的方案。
4. **管理资产**：将 Logo、背景和落版等常用素材导入资产库，或引用原路径。引用文件被移动后需要重新定位。
5. **核对输入输出**：加载模板时留意路径是否沿用当前目录或模板目录，避免处理了错误的素材。

### 4.2 裁切、改尺寸与水印

| 任务 | 配置思路 | 预览重点 |
|---|---|---|
| 保留指定时间段 | 设置开始与结束秒数，只保留需要的部分 | 开头、结尾与成片时长 |
| 删除指定时间段 | 设置需要删除的区间 | 删除处的画面与声音衔接 |
| 保留或删除末尾 N 秒 | 从结尾计算时间，适合处理已有片尾 | 是否切掉了需要的内容 |
| 比例适配 | 如 9:16 转 4:5，以模糊背景填补画布 | 主体是否完整，模糊强度是否合适 |
| 动态水印 | 选择动态素材并调整布局，涉及透明度时检查颜色保护 | 水印位置、透明度与颜色 |
| PNG 静态水印 | 选择透明底图片并调整大小、位置 | 是否挡住字幕或重要画面 |

### 4.3 背景、Logo 与两种落版

**批量换背景图**：准备目标比例的背景海报，在可视化叠加中添加背景和原视频，调整视频的位置与大小。例如同一批视频可以分别套用「飞跃 1:1 包装」和「飞跃 16:9 包装」。

**批量贴 Logo**：为同批视频使用统一位置；画面构图不同时，可对个别视频单独微调。先检查预览，避免遮住字幕或主体。

**浮层落版**：在正片最后一段叠加带透明度的落版素材，原视频仍在下方播放。需要设置开始叠加的时间，并检查画面和音频的重叠效果。

**拼接落版**：正片结束后接一段完整落版视频。需要落版自己的声音时，启用保留原声，并检查结尾预览。

### 4.4 处理链路、预览与输出

1. 左侧勾选功能，中间显示相应设置卡片；检查处理链路中的启用状态与顺序。
2. 顺序会影响结果。例如先加落版再贴背景，与先贴背景再加落版的成片可能不同。
3. 画布预览用于看构图；短片段预览用于看实际处理后的画面、动效和声音。
4. 智能预览或手动选择开头、中间、结尾约 3 秒，优先检查本次修改涉及的位置。
5. 设置输出目录，开始处理，通过进度和日志确认结果；暂停与停止后也应核对已经写出的文件。
6. 遇到同名输出时，根据需要选择自动改名、跳过或覆盖；覆盖前确认目标文件可替换。

## 5. 规范命名操作详解

### 5.1 命名模板与字段

序号、品牌、语言、作者、日期和标签等字段可按团队规则组合，顺序可以调整，序号不必固定在最前面。日期可跟随电脑当天日期；常用标签库可以维护自己的常用词。

例如，团队可以自行配置类似下面的交付格式，具体分隔符、补零与字段顺序以设置为准：

```text
001_飞跃_产品介绍_20261005_SasaFreya.mp4
002_飞跃_功能演示_20261005_SasaFreya.mp4
```

### 5.2 六类文件名微调规则

| 规则 | 用途 | 检查点 |
|---|---|---|
| 添加与补齐 | 在指定位置加入内容，或补齐长度 | 位置、补齐字符与长度 |
| 替换 | 查找指定文本并替换，可调整匹配范围 | 是否区分大小写，是否只替换指定部分 |
| 删除与保留 | 删除空格、指定内容，或仅保留需要的片段 | 保留前后范围与分隔符 |
| 移动 | 按位置或分隔符移动文件名中的片段 | 起点、长度与目标位置 |
| 字母大小写 | 统一大写、小写、首字母大写或反转大小写 | 缩写与专有名词是否符合预期 |
| 旧版清理 | 按相关清理规则处理历史命名 | 先预览，按需要启用 |

这些规则按需使用；第一次命名可以先只配置字段模板，不必同时打开所有微调功能。

### 5.3 对照检查与执行

1. 添加素材，配置命名模板，查看原文件名与新文件名对照。
2. 通过勾选分批处理；少量不满意的条目可单独修改。
3. 对照更名可复用另一组文件名；附加模式可把内容接到原名上。注意同目录不能出现冲突名称。
4. 扫描不到子文件夹中的素材时，检查是否启用了包含子文件夹。
5. 先用复制的文件测试，核对结果后再对正式素材执行。

## 6. 裂变与设置操作详解

### 6.1 单源、多源与预处理

- **单源多方案**：同一个输入文件夹，引用多个完整方案，按顺序分别输出。
- **多源多方案**：多个输入单元分别配置素材、方案和输出，按单元组织处理。
- **预处理**：先用一套方案处理输入，再让预处理结果进入后续方案。没有共同前置步骤时可以不启用。

### 6.2 方案管理与视图

1. 设置输入文件夹与输出根目录。
2. 在画布添加方案，引用已保存模板或新建组合；配置每套方案的功能与顺序。
3. 修改分支名时注意它会影响输出文件夹名称，例如「方案 A-飞跃方形包装」。
4. 用思维导图或地铁线路查看关系，用列表整理分支；根据习惯切换视图。
5. 保存组合，便于以后复用多个方案的组织关系。
6. 执行结束后查看各方案成品；需要衔接团队序号时，可使用重编号功能并先核对预览。

### 6.3 偏好设置与记忆空间

| 设置 | 作用 |
|---|---|
| 默认打开页 | 启动时进入视频批处理、规范命名或批量裂变 |
| 自动加载方案 | 按偏好加载上次使用或指定的方案／组合 |
| 主题皮肤 | 选择奶油粉白、蓝白、黄绿、黑紫等外观 |
| 裂变默认视图 | 选择常用的思维导图、地铁或列表视图 |
| 默认输出路径 | 减少每次选择目录的重复操作 |
| 备份相关设置 | 按配置保留输出备份；使用前确认备份范围 |
| 完成后命名提示 | 裂变完成后提示进入规范命名流程 |

记忆空间保存的是使用偏好，不会替你确认素材路径仍然有效，也不代替对成品的检查。

## 7. 三个实际使用场景

### 7.1 日常包装：一套模板处理一批视频

1. 加载「飞跃日常包装」模板。
2. 选择输入和输出目录，检查 Logo、水印与落版素材。
3. 预览开头和结尾，确认后开始批处理。
4. 按交付规则规范命名。

### 7.2 多尺寸交付：同一素材输出三套方案

1. 保存 1:1、16:9、4:5 三套背景与 Logo 布局方案。
2. 在裂变页为同一输入单元引用这三套方案。
3. 选择输出根目录并执行，分别检查三个方案文件夹。

### 7.3 多批次整理：队列顺序处理

1. 为各批素材配置输入、输出与方案，加入生产队列。
2. 检查队列后开始执行；使用监视目录时，先检查扫描入队的内容。
3. 按日志核对每批结果。监视仅帮助入队，处理仍需启动队列。

## 11. 快速上手

### 11.1 先做一套可复用方案

1. 在「视频批处理」中选择输入文件夹，也可以尝试拖入文件夹。
2. 勾选需要的功能，选择 Logo、背景图或落版等素材。
3. 调整参数与执行顺序，选择独立的输出目录。
4. 预览相关片段，检查位置、比例、结尾与声音。
5. 将配置保存为方案模板，开始处理。下次加载模板即可复用。

模板记住的素材路径需要继续有效；素材被移动或删除后，应重新选择路径。

### 11.2 再做多方案输出

1. 进入「批量裂变」，添加输入单元。
2. 为单元选择多套方案，需要时设置预处理。
3. 检查方案名称、输入位置和输出根目录。
4. 开始执行，到各方案子文件夹查看成品。

需要统一交付命名时，可以使用「规范命名」页面，先检查原名与新名的对照结果。

## 13. 常见问题

### 13.1 素材会上传到服务器吗？

桌面视频包装流程读取本地素材，将成品写入你指定的本地输出目录，无需上传视频到官网。

### 13.2 这是 AI 视频生成工具吗？

当前主要功能是视频包装、规范命名和批量工作流。它不提供网页演示中直接生成完整视频的 AI 服务。

### 13.3 浮层落版和拼接落版有什么区别？

浮层落版在正片结束前叠加，与原画面重叠；拼接落版接在正片结束之后。需要落版自己的声音时，检查保留落版原声的设置，并通过结尾预览确认。

### 13.4 拖入文件夹没有反应怎么办？

先使用界面的文件夹选择按钮，确认选中的是有效文件夹，并尝试一个只含少量视频的本地目录。若按钮选择也失败，请记录系统版本、操作步骤和日志，提交反馈。

### 13.5 打开空白、启动退出或导出失败怎么办？

确认已完整解压，并检查是否有系统拦截提示。若仍失败，请通过 Issues 提供复现步骤、错误截图和可用日志；导出问题请补充视频格式、启用功能及失败发生的位置。反馈材料请去除私人素材、邮箱以外的敏感账号信息和其他不希望公开的内容。
